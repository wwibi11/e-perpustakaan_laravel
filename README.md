# E-Perpustakaan

Sistem Informasi Perpustakaan berbasis Laravel.

## Fitur
- Manajemen Buku & Eksemplar
- Manajemen Anggota
- Peminjaman & Pengembalian
- Reservasi Buku
- Laporan & Statistik
- Multi-role (Admin, Pustakawan, Staff)

## Teknologi
- Laravel 13
- PHP 8.3
- MySQL/MariaDB
- Bootstrap 5
- Font Awesome

## Instalasi
1. Clone repo ini
2. `composer install`
3. Copy `.env.example` ke `.env`
4. `php artisan key:generate`
5. Import database `database/eperpus_db.sql`
6. `php artisan serve`
